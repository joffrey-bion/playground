# Playground

This is a playground project to experiment with Kotlin things.

It provides a versions catalog with ready-to-use dependencies in their latest versions,
and multiple modules with different structures.

The project is built with [the Kotlin Toolchain](https://kotlin-toolchain.org):

| Command         | Description                        |
|-----------------|------------------------------------|
| `kotlin build`  | Compile and link all modules       |
| `kotlin test`   | Run the tests                      |
| `kotlin run`    | Run `playground-jvm-app`           |
| `kotlin update` | Update the toolchain wrapper       |
